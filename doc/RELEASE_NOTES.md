# TCER v1.5.0

把「可选中复制」从用户消息子窗口推广到全应用的 41 处内容性文本（会话 ID、文件路径、诊断说明、洞察建议、规则原文、发布说明等），并优化两处右键菜单与「立即更新」按钮。

## 文本可选中复制（全应用推广）

- **此前**只有「用户消息」子窗口里的正文能拖选 + Ctrl+C + 右键「复制」，其余展示文本（会话详情的 session ID / 工作目录、涉及文件 / 项目记忆文件的路径、各类诊断警告、项目视角右栏的洞察 / 规则 / 推荐、发布说明等）都只能看不能拷。
- **现在**这些「用户最常想复制的内容性文本」统一改用 `SelectableLabel`（伪装成 Label 的只读 Text），均可拖选、Ctrl+C、右键「复制」。
- **覆盖 41 处**：会话详情（session ID / 工作目录 / 时间 / 未见文件警告）、模型使用 / 成本明细（未匹配价表警告）、个人基准说明、涉及文件 / 项目记忆文件（文件路径 / 搜索路径 / 目录）、删除确认、检查更新（版本信息 / 发布说明）、项目视角右栏（CLAUDE.md 规则建议 / 推荐 / 洞察 / 会话 ID / 活动概要 / 各说明文）。
- **不改动**：按钮文字、表头、键前缀、计数徽章、Tooltip、指标网格的数值单元格（用 textvariable，改造成本高且复制价值低）等结构性文字。
- **配套清理**：项目视角右栏原有的「复制规则」「复制指令」按钮（文本已可直接选中复制，按钮冗余）移除；删除因此变孤儿的 `_wrap_to_width` / `_copy_rule`。

## 右键菜单优化

- **左栏项目列表**：「查看项目概览（指标分类）」「查看会话详情视图」改名为更贴切的「项目视角」「会话视角」，图标换为对应的彩色视角标识（项目=橙黄、会话=蓝），与顶部视角切换按钮配色一致。
- **中栏会话列表**：「置顶」「加红旗」从菜单底部移到最上面（高频卡片状态管理操作，与卡片角标位置呼应）。

## 其他

- 检查更新弹窗的「立即更新」按钮放大（内边距加大），作为主操作视觉更突出；`flat_button` 新增可选 `pady` 参数（默认值不变，不影响其他按钮）。「前往下载」fallback 保持原样（两者互斥显示）。
- `SelectableLabel` 增加 `wraplength` 兼容参数；替换洞察区文本后不再需要 `_wrap_to_width`（`SelectableLabel` 按容器实际宽度自动换行 + 撑高）。

## 说明

- 客户端纯离线、零第三方依赖不变；指标公式不变。
- GUI 冒烟测试 35 项全过（新增可选中复制断言、适配 SelectableLabel 文本收集）。
