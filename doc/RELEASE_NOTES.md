# TCER v2.1.1 更新说明

**状态栏常驻选中上下文，会话右键菜单收敛，复制动作反馈**

---

## 一句话总结

状态栏新增常驻的「选中上下文」段——始终显示当前选中的项目，选中会话时追加会话标识；会话右键菜单收敛七个重复入口；所有复制动作完成后状态栏即时反馈「已复制 "…"」；分析完成的状态措辞优化。

---

## 更新内容

### 1. 状态栏常驻选中上下文

- 状态栏左侧新增上下文段：仅选中项目时显示「**项目 X**」；选中会话后显示「**项目 X › 会话 10-25 16:46**」。
- 会话标识采用开始时间短格式（与会话卡片一致）——**会话标题不上状态栏**（过长）。
- 切换项目、点选/取消会话、删除会话、时间筛选改选等所有选中变化路径即时刷新。

### 2. 会话右键菜单收敛

- 移除七个重复入口：查看工具调用、查看涉及文件、查看模型使用、在趋势图中定位、复制会话 ID、复制会话标题、复制摘要——这些数据在**指标看板格与趋势分析各有主入口**。
- 菜单收敛为：置顶/加红旗 ‖ 查看会话记录 ‖ LLM 四项深度解读 ‖ 在资源管理器中打开 / 复制会话路径 ‖ 删除会话。

### 3. 复制动作状态栏反馈

- 「复制会话路径」「复制项目路径」完成后，状态栏即时显示 **`已复制 "C:\...\xxx.jsonl"`**——不再静默无反馈。
- 剪贴板始终存全量内容；状态栏显示超长（>72 字符）时做中段省略，不挤占右侧图标区。

### 4. 状态措辞优化

- 分析完成的状态消息由「完成 · 共 N 个会话」改为「**分析完成 · N 个会话**」——补上主语，与加载时的「分析中… 项目名」前后对应，消除「什么完成了」的困惑。
