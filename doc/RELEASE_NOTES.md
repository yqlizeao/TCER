# TCER v2.0.2 更新说明

**模型对比多模型混用归因修正，会话记录阅读器深度增强与排版/交互精雕**

---

## 一句话总结

修复「模型对比」在混用多模型会话中把会话级代码产出与行为指标按 Token 占比分摊导致两模型数据完全克隆的失真问题；全面升级「会话记录」阅读器——新增逐轮遥测胶囊、6 色语义概览标尺、「改动」视图涉及文件汇总卡片、Diff 纯净复制新代码、代码块语法着色与长代码折叠、中日韩行首禁则排版，以及浏览器级紧贴选区与无死角目录交互。

---

## 核心更新

### 1. 模型对比：多模型混用会话归因修正（数据真实性）
- **问题**：此前 `compare_models` 对混用多个模型的同一会话，将净增代码行、工具调用、读写次数、返工率、先读后写率等会话级指标按各模型 Token 占比 $w$ 分摊。在单会话视角下，凡除以会话权重 $w$ 或分子分母同乘 $w$ 的指标（净增行/会话、探索/编辑占比、读写比、返工率、先读后写率、涉及文件/会话）因 $w/w=1$ 恒等抵消，导致两个模型显示一模一样的克隆数值；而「代码效率（行/$）」则退化为「Token 效率 × 常数」，造成严重误导。
- **修正**：
  - Token 用量、成本、缓存命中率仍按 `per_model` 精确归因；
  - 代码效率与「代码质量与行为」8 项指标仅统计各模型的**单模型独立会话**；当某模型仅出现在多模型混用会话中（`mixed_only=True`）时，诚实显示「不适用」并附悬浮说明，杜绝伪造归因；
  - 修正 Antigravity 逐步模型名提取：补充读取 `model_usage.model` 字段，并将轨迹展示用友好名（如 `Gemini 3.8 Flash`）统一归一为价表标准模型 ID，消除同源模型拆列。

### 2. 会话记录阅读器：6 项深度增强
- **逐轮成本/Token 与代码变更遥测胶囊**：全数据源（Claude Code、Codex、OpenCode、omp/Pi、Antigravity）支持逐轮模型、Token、成本与增删行归集；每轮 AI 标题行右侧内嵌 `模型 · tok ($cost) · +added −removed` 遥测胶囊，高消耗轮次自动标记紫色 `▲` 热点高亮，点击胶囊可在底部状态栏查看输入/输出/缓存读/缓存写明细。
- **右侧 6 色语义概览标尺（Overview Ruler）**：滚动条旁新增 `10px` 6 色密度标尺——绿色（代码改动）、紫色（高成本/高 Token 热点轮）、青色（工作目录模块切换）、蓝色（≥15 步深度长链轮）、金色（搜索命中）、红色（会话中断/系统级异常，刻意过滤高频普通单步工具报错以保证高信噪比），支持悬停预览与点击直达。
- **「改动」视图顶部「涉及文件汇总」卡片**：切换到「改动」视图时，顶部自动汇总全会话所有被修改文件、参与轮次轨迹与累计 `+added −removed` 行数；编辑 ≥ 3 次的文件自动标记橙色 `返工 N 次` 徽标，左键直达首处改动并自动展开 Diff，右键弹出本地路径定位菜单。
- **截断思考与长工具参数一键懒加载全文**：超过预览上限被截断的思考块（`… 展开完整思考（共 N 字符）`）与工具命令/参数（`… 展开完整参数（共 N 字符）`）保留原始引用（JSONL / SQLite），点击即可后台按需读取完整原文并原位展开。
- **Diff「复制新代码」与纯净选区复制**：Diff 头部新增「复制新代码」（自动剥离 `-` 删除行与首列符号）与「复制 Diff」内联动作；Diff 行号与首列 `+/-` 符号标记为界面装饰（`ui_chrome`），鼠标直接框选 Diff 代码行按 `Ctrl+C` 即可复制出不含行号与加减号的纯净可运行代码。
- **大纲卡片代码量徽标与信号标记**：右侧「对话目录」卡片步骤行直接展示本轮 `+added −removed` 代码量徽标，并以紫色 `◆`（成本热点）与青色 `◈`（跨模块切换）直观标出关键轮次。

### 3. 会话记录阅读器：排版与交互精雕
- **指标看板联动升级**：淘汰旧版简陋的「用户消息」弹窗，看板头部新增醒目「会话记录」按钮，点击「用户提问」指标格直接拉起完整会话记录阅读器。
- **Markdown 深度排版**：
  - **中日韩行首禁则（Kinsoku）**：正文气泡、Markdown 段落与目录卡片全面接入避头尾折行算法，标点不再孤立落入行首；
  - **围栏代码块语法着色与折叠**：支持 Python / JS / TS / Go / Rust / Shell / SQL / JSON 零依赖关键字、字符串、注释、函数名、数字语法高亮，超过 80 行的长代码块自动折叠并提供一键展开；
  - **表格内联样式与信噪比优化**：支持单元格内行内代码胶囊（`` `code` ``）与状态符号语义着色（`✓` 绿 / `⚠` 橙 / `✗` 红），去除数据行间生硬的满宽横线，改为仅表头下 1px 细线 + 斑马纹底色；
  - **本地真实路径感知**：行内代码若对应本地真实存在的文件或目录，自动渲染为青色下划线链接，左键打开/定位、右键呼出资源管理器菜单。
- **浏览器级紧贴选区（`sel_vis`）**：解决 `tk.Text` 原生选中态将行首缩进、气泡补白、分轮线一并染蓝形成锯齿色块的问题，选区严格紧贴真实文字字形。
- **零死角目录与工具栏去重**：右侧对话目录整卡任意位置点击零死角命中并锁定选中态（消除滚动回写跳变）；精简页头重复按钮（「展开/收起全部」「导出 Markdown」收拢至「显示选项」菜单）；单会话时自动隐藏 `< 1/1 >` 切换器；点击「异常轮次」循环跳转并仅对目标行做单行柔和闪烁。
