# TCER v2.0.3 更新说明

**OpenResearch 级圆角矢量渲染引擎与五大新组件，智能项目/会话视角，指标看板紧凑化**

---

## 一句话总结

界面渲染层整体升级为三层自适应抗锯齿圆角矢量管线（Tk 9.0 原生 SVG → Pillow 超采样 → 纯标准库 SDF PNG），新增 SurfaceCard / SegmentedControl / ToggleSwitch / StatusBadge / RoundedEntry 五大基础组件并铺开到全部视图与弹窗；项目/会话视角改为由当前选中智能驱动（移除手动切换开关，点项目不再默认选中第一个会话）；指标看板「代码产出与质量」小分类平铺紧凑化；CI 升级 Python 3.14 / Tcl-Tk 9.0.4，触控板高精度滚动与 Codex `.zst` 会话在打包版直接可用。

---

## 核心更新

### 1. 三层抗锯齿圆角矢量渲染引擎（渲染质量）

- **三层自适应管线**，按运行环境自动择优、逐级回退，任一环境都不退化为直角硬锯齿：
  1. **Tier 1 · Tk 9.0+ 原生 SVG**：`tk.PhotoImage(format="svg")` 矢量光栅化（NanoSVG）；
  2. **Tier 2 · Pillow 2× LANCZOS 超采样**：开发机装有 Pillow 时走超采样缩放；
  3. **Tier 3 · 纯标准库 SDF**：基于有向距离场（Signed Distance Field）亚像素边缘积分 + `zlib`/`struct` 内存直出 PNG 字节流——**零第三方依赖**的 PyInstaller 单文件版同样具备丝滑圆角与 1px 细描边。
- **9-slice 圆角容器**（`draw_rounded_box` / `RoundedFrame`）：任意宽高动态伸缩，缩放时仅做坐标位移、**0 贴图重分配**；`RoundedFrame` 直接支持 pack/grid 几何管理，子控件无痕内嵌。
- 全部圆角贴图带进程级缓存（按解释器 / 尺寸 / 颜色 / 管线档位键控）与防膨胀剪枝，反复重绘零额外计算。

### 2. 五大新组件，界面全面铺开（视觉体系）

- **`SurfaceCard`**：分组圆角细描边卡片——外部小节标题 + `SURFACE_CARD` 圆角容器 + 1px `BORDER_SUBTLE` 抗锯齿描边 + 卡内 1px `DIVIDER` 行间分隔线；声明式 `add_row` / `add_divider`。
- **`SegmentedControl`**：圆角分段切换胶囊槽（细描边底槽 + 凸起圆角激活滑块），用于会话阅读器「全部/对话/改动」等切换。
- **`ToggleSwitch`**：36×20px 抗锯齿拨杆开关（开启态 ACCENT 蓝轨白钮，绑定 `BooleanVar`）。
- **`StatusBadge`**：语义状态徽标胶囊，`neutral / success / warning / error / info` 五种微光暗底 + 同色相 1px 细描边 + 可选状态圆点。
- **`RoundedEntry`**：圆角细描边单行输入框——常态 1px 细描边、持焦平滑切换 ACCENT，内置轻量占位提示且绝不污染 `.get()`。
- **铺开范围**：上传 / LLM 配置 / 模型详情 / 工具调用 / 术语库等全部弹窗卡片化；侧边栏、模型对比、趋势分析组头、会话对比、会话时间线同步升级。
- **活动栏重构为可折叠悬浮圆角导航**：展开态 148px「图标 + 中文名称」圆角胶囊行，点击右上角一键收起为 50px 纯图标导航（悬浮提示完整名称），偏好持久化、重启恢复。
- **弹窗页头重做**：去除厚重灰顶条与自绘关闭按钮，改为留白页头 + 1px 分隔线，靠标题栏 × 与 Esc 关闭。
- **主题 token 扩充**：`SURFACE_CARD` / `BORDER_SUBTLE` / `DIVIDER` 表面阶梯，`RADIUS_S/M/L/XL/FULL` 圆角半径阶梯 SSOT，四色状态描边（警示/错误/成功/信息）。

### 3. 智能项目/会话视角（交互重构）

- **视角 = 当前选中**，移除侧栏顶栏「项目/会话」切换分段控件与项目右键「项目视角/会话视角」菜单项：
  - 点会话卡（或效率榜排名行、趋势图定位）→ 即入会话视角；
  - 点项目卡 → 即回项目汇总视角；
- **两条丝滑回程**：再点已选会话卡 = 取消选中回项目汇总；会话视角下点当前项目卡 = 只切视角**不重算**（数据没变）。
- **点项目不再默认选中第一个会话**——项目汇总视角干净起步；同项目重分析时，上一选中会话仍可见则延续选中与会话视角，否则落回项目视角。
- 右键「刷新此项目」保留显式重算语义，会话视角下刷新不再被切视角快路径吞掉。

### 4. 指标看板紧凑化

- 「代码产出与质量」组内「基础 / 行为 / 质量」小分类标题行移除，40 项指标平铺进同一网格，扫读密度更高；
- 子类结构保留在指标 SSOT（HTML 报告仍按子类分节导出），仅看板不再重复渲染。

### 5. Tcl/Tk 9.0.4 与 Python 3.14 双轨升级（CI 与兼容性）

- CI 构建升级 **Python 3.14**：官方 Windows / macOS 构建内置 **Tcl/Tk 9.0.4**（原生 SVG 光栅化、`<TouchpadScroll>` 高精度触控板事件）与标准库 `compression.zstd`——**Codex `.jsonl.zst` 会话在打包版直接可读**（此前需 Python 3.14+ 源码运行）。
- **触控板双指高精度滚动**：Tk ≥9.0 加绑 `<TouchpadScroll>`，按「官方 API 优先」三级解码回退（`tk::PreciseScrollDeltas` → 多值列表 → 32 位打包惯例），亚像素增量累积为平滑滚动步长；Tcl/Tk 8.6 环境行为不变。
- CI 新增运行时校验步骤：三层圆角管线在发布构建机上**逐层实测**（SDF 编码器字节合法性 / Tk 9 SVG 探测与出图 / 9-slice 四角贴图），另加 PyInstaller 产物存在性检查。

### 6. 稳定性与工程修正

- **修复弹窗控件树泄漏**：`ToggleSwitch` / `SegmentedControl` / `RoundedEntry` 的 tk Variable trace 现随控件销毁解除——此前弹窗每开一次，已销毁控件子树被解释器级 Variable 闭包钉在内存里。
- **补齐 `configure`/`cget` 四种调用形契约**（`RoundedFrame` / `StatusBadge` / `RoundedKpiChip`）：单键查询返回 Tk 标准 5 元组、dict 形生效、无参返回选项枚举；`cget("bg")` 修正为返回稳定父底色（此前会随悬停态或徽标种类漂移）。
- `SurfaceCard` 不再静默改写 `bg` 参数（原「传 BG 偷换 SURFACE_CARD」特判删除，全部调用点显式化）。
- 活动栏选中态不再挪用结构 token `BORDER` 作描边（主题纪律：结构分隔与状态表达严格分 token）。
- 手风琴表头、阅读器分轮线/标题行距等排版细节微调。
