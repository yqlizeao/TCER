# TCER v2.1.2 更新说明

**Antigravity 计数全面修正与 cc-switch 隔离终端接入，Claude 覆盖与守恒审计，浮窗不再重复弹出**

---

## 一句话总结

对本机全部 Antigravity（agy）会话做了原始数据普查，修正了并行工具调用漏计、失败编辑计入代码行、上下文压缩用量全漏等多处计数错误，并支持读取 cc-switch「以此供应商打开终端（环境隔离）」产生的 agy 会话；新增 `python -m tcer.audit --coverage`：逐值普查 Claude Code 原始数据，上游格式一有漂移就点名报出，不再静默跳过；修复悬停浮窗叠出两三个的问题。

> **数值会变化**：Antigravity 会话的 Token、成本、工具调用数、代码行数会比 v2.1.1 更高（更接近真实），这是修正漏计的结果，不是新的偏差。详见第 1 节。

---

## 更新内容

### 1. Antigravity 计数修正（数据真实性）

逐条对照 agy 会话库的原始记录后发现并修正：

- **并行工具调用只计了第一个**：模型一次发起多个工具调用时，同一步里有多个调用，此前只读取首个。本机漏计 490 次调用，其中 185 次是编辑/写入，对应的代码行也一并漏计。现在逐个统计。
- **失败的编辑被计入代码行**：agy 的编辑失败（`Could not successfully apply…`）此前照样回放进代码行。现在与其他数据源一致——**工具结果成功后才计入代码行**；会话末尾尚无结果的调用不回放。
- **上下文压缩的用量全部漏算**：agy 每次压缩上下文都是一次真实的 LLM 调用，但它的用量不写进生成记录。现在按响应 id 去重后补入 Token 与成本，同时开始统计「上下文压缩」次数（此前该指标显示「不适用」）。压缩记录不带模型名，**按前一次回复所用模型计价（推断）**。
- **内容被清空的步骤**：个别会话中，agy 会把早期步骤的调用内容清空（状态码 5）。此前这些步骤被误判为工具报错、提问被解析成乱码、其中的编辑全部漏计。现在从工具结果中保留的调用回显补回调用与代码行，提问取备份正文，不再出现乱码。
- **`manage_task` 不再被当作子代理**：它是 agy 查看/停止后台命令的工具，此前被归为 `Task`（子代理调度）。现在保留原名。

以本机 30 个 agy 会话为例：成本 $138.57 → $142.31（+2.7%，全部来自压缩调用）；新增代码行 38,349 → 41,594；工具调用 +602 次；工具报错 −101 次。13 个会话完全不变。

### 2. 支持 cc-switch 隔离终端中的 Antigravity 会话

- cc-switch 的「以此供应商打开终端（环境隔离）」会把 agy 会话写到 `~/.cc-switch/agy/<供应商id>/antigravity-cli`，此前 TCER 读不到。
- 现在自动扫描默认目录与全部隔离目录；**同一工作目录的会话合并成一张项目卡**；同一会话出现在多个目录时只计一次（取最新文件）。
- 设置了 `ANTIGRAVITY_DIR` 等环境变量时只读指定目录，不扫描 cc-switch。

### 3. Claude Code 覆盖与守恒审计（`--coverage`）

闭环审计用同一套解析逻辑重算，只能证明「自洽」；数据格式漂移时，解析器会静默跳过新东西，自洽检查照样全绿。新增的覆盖审计补上这一块：

- **逐值普查**：直接读取原始 JSONL（不经解析器），统计行类型、system 子类型、附件类型、内容块、usage 字段等实际出现的每一个值。
- **登记表**：每个值必须登记为「已处理」或「已知忽略（附理由）」；**未登记的一律报「未知」**，并给出首次出现的文件与行号。
- **计价字段白名单**：`speed`、`service_tier`、`inference_geo` 等出现会改变价格的取值（如 fast、数据驻留）时报「取值异常」。
- **守恒检查**：工具结果与调用对应、有用量的行都有 message.id、同一回复的快照只增不减、子代理都有父会话、解析器工具调用数与独立计数一致等；进行中会话的未完成调用、请求与回复数量差额等如实列为提示。
- 本机 699 个文件、22.5 万行普查结果：**无未知项、无取值异常**，普查覆盖到 Claude Code 2.1.311。
- 用法：Claude Code 升级后运行 `python -m tcer.audit --coverage`，PASS 表示新版本没有引入登记表之外的东西。

普查同时明确了本地数据**无法覆盖**的部分：Claude Code 生成会话标题、离开摘要等附带 LLM 调用的用量不写入会话文件，TCER 无法计入；报错、被拒绝或被中断的请求是否计费，本地也无法判断。

### 4. Claude 服务端工具调用重发去重

- rewind 重写历史时，同一次服务端工具调用（`server_tool_use`）会被重复写入，此前会被计两次。现在与普通工具调用一样按 id 只计一次。
- 本机现有数据中未出现这种重复，现有数字不变。

### 5. 悬停浮窗不再叠出多个

- 模型对比页的模型卡片等处，鼠标移入时会同时弹出两三个错位的价格浮窗。原因是嵌套的界面元素各自挂了浮窗，鼠标跨过重合边界时会同时触发。
- 现在全局同一时刻只显示一个浮窗，所有嵌套挂浮窗的位置一并修复。

### 6. 会话记录阅读器（Antigravity）

- 工具结果按调用 id 精确配对（此前按出现顺序推断）。
- 内容被清空的调用会从结果回显中补出显示；失败状态的结果标为错误。
