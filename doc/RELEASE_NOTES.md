# TCER v1.5.5

价表定价口径升级：统一录厂商**标准价**（不再随限时促销漂移）、峰谷分时录**闲时档**；新增条目级**计价备注**，价表悬浮（tips）可直接看到多轨价、峰谷时段与分段计费信息。含 models.dev 交叉审计修正。

## 定价口径（本次定调）

1. **标准价**：录厂商官方标准价，不用限时促销/介绍价——成本估算不再随促销期漂移，历史会话间可复现比较。
2. **峰谷分时录闲时档**：DeepSeek V4 全系（v4-flash / -0731 / v4-pro / chat / reasoner）提前切换至 2026-08-16 起的闲时价。
3. **多轨价与分段计费进备注**：促销价、峰时价、Batch/Priority 档、同模型分段计费等记入条目 `_note`，GUI 价表悬浮展示。

## 新增：价表悬浮显示计价备注

模型卡价表悬浮（tips）现追加 `ℹ️` 备注行，与四个展示单价同源。示例（DeepSeek V4 Flash）：

```
输入　　　$0.22/百万 …
ℹ️ 峰谷分时（2026-08-16 起）：本价为闲时档；峰时（北京 09-12/14-18 点）
   加倍：输入 0.44 / 输出 1.32 / 缓存命中 0.014
```

现有 12 个条目带备注（claude-sonnet-5 / gemini-3.7-flash 介绍价轨、DeepSeek 峰谷、glm-5v-turbo 分段计费、kimi/o3-mini 修正说明、glm-5.3 占位说明等）。
